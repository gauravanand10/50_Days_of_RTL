# Day 30 - Recursive Systems

## Objective

Learn the concept of **Recursive Systems** in Verilog by implementing a **Fibonacci Number Generator**. Understand how recursive mathematical sequences can be efficiently implemented using sequential logic, registers, and finite state progression. Also explore iterative hardware implementation techniques since true recursion is generally not synthesizable in RTL.

---

## Design

### Fibonacci Generator

Inputs:

- Clock (`clk`)
- Reset (`reset`)
- Start (`start`)
- Number of Terms (`n`)

Outputs:

- Fibonacci Number (`fib`)
- Done (`done`)

Functionality:

- Generates Fibonacci numbers sequentially.
- Uses registers to store the previous two Fibonacci values.
- Computes one Fibonacci number every clock cycle.
- Asserts the `done` signal once the required term has been generated.

---

## Flow

1. Learn Recursive Systems
2. Understand the Fibonacci Sequence
3. Initialize the First Two Terms
4. Store Previous Results
5. Generate the Next Fibonacci Number
6. Repeat Until the Required Term
7. Assert Completion Signal
8. Create Testbench
9. Analyze Waveforms

## Key Observation

During simulation:

- The first two Fibonacci numbers are initialized to **0** and **1**.
- Each new Fibonacci number is generated by adding the previous two values.
- Registers continuously update to hold the latest sequence values.
- One Fibonacci number is produced every clock cycle.
- The `done` signal indicates successful completion of the requested computation.

## Assignment

Design a **Factorial Generator** that computes the factorial of an input number using sequential hardware. Write a suitable testbench to verify different input values and observe the multiplication process over multiple clock cycles.

---

## Assignment Design

### Factorial Generator

Inputs:

- Clock (`clk`)
- Reset (`reset`)
- Start (`start`)
- Number (`n`)

Outputs:

- Factorial Result (`fact`)
- Done (`done`)

Internal Blocks:

- Counter
- Multiplier
- Result Register
- Control Logic

Functionality:

- Initialize the factorial result.
- Multiply the result with the current counter value.
- Increment the counter every clock cycle.
- Continue until all multiplication steps are completed.
- Assert the `done` signal after computing the factorial.

---

## Assignment Flow

1. Initialize Result Register
2. Initialize Counter
3. Multiply Current Result
4. Increment Counter
5. Check Completion
6. Assert Done Signal
7. Create Testbench
8. Verify Different Inputs
9. Analyze Waveforms

---

## Key Observation

For different input values:

- The factorial result is generated over multiple clock cycles.
- One multiplication is performed during each clock cycle.
- Larger input values require more computation cycles.
- The `done` signal indicates that the final result is available.
- Sequential implementation minimizes hardware compared to fully combinational multiplication.

## Comparison: Recursive Algorithm vs Iterative RTL Implementation

| Feature | Recursive Software | Iterative RTL |
|---------|--------------------|---------------|
| Execution | Function Calls | Clock Cycles |
| Memory Usage | Stack | Registers |
| Synthesizable | No | Yes |
| Performance | Software Dependent | Hardware Dependent |
| Hardware Friendly | No | Yes |
| Preferred in RTL | ❌ | ✅ |

---

## Conclusion

Recursive mathematical problems such as the Fibonacci sequence and factorial calculation are implemented in hardware using **iterative sequential logic** rather than true recursion. By storing intermediate values in registers and updating them every clock cycle, RTL designs efficiently compute complex sequences with minimal hardware resources. Understanding these techniques is essential for designing arithmetic accelerators, control logic, and sequential processing units in FPGA and ASIC systems.
